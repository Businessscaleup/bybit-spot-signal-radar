Bybit Spot Signal Radar — Mobile Edition

Upload app.py, requirements.txt, and README.md to your existing GitHub repository, keeping app.py as the Streamlit entry file. Wait for Streamlit Community Cloud to redeploy, then open the site in Android Chrome with Desktop site turned off.


Features: main-page mobile controls, active Spot pair scanning, completed-candle-only analysis, EMA/RSI/volume/ATR rules, progress, error warnings, signal copy, and CSV export.


Important: qualified setups are not win probabilities or guarantees. Strategy profitability has not been established. Spread, slippage, actual fills and fee tiers can differ from the approximation. Rate limits can make scans incomplete. This version uses public data only and does not connect to private accounts, place orders, or monitor positions.
